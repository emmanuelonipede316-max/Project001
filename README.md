## 4. Concepts Learned

### Offensive Security

Offensive security involves testing systems by thinking and
acting like an attacker in an authorized environment.

The purpose is to identify weaknesses before malicious
attackers can exploit them.

### Penetration Testing

Penetration testing involves identifying and safely exploiting
security weaknesses to understand their potential impact.
